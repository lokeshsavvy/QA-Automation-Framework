# QA Automation Framework

## Project
GUVI Automation Testing Project using Python, Selenium, PyTest, and Page Object Model (POM).

## Tools Used
- Python
- Selenium
- PyTest
- PyTest HTML Reports

## Test Cases
1. Verify URL
2. Verify Title
3. Verify Login Button
4. Verify Sign Up Button
5. Verify Sign Up Navigation
6. Verify Login
7. Verify Invalid Login
8. Verify Header Menu Items
9. Verify Chat Widget
10. Verify Logout

## Run Tests

pytest -v -s

## Generate Report

pytest -v --html=reports/guvi_report.html --self-contained-html
